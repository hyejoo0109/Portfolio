# 오혜주 포트폴리오

Vercel에 연결된 정적 웹사이트입니다. `index.html` 하나와 `img` 폴더로 되어 있어요.

## 직접 고치는 법
1. GitHub에서 `index.html` 열기 → 오른쪽 위 연필 아이콘
2. `Ctrl+F`(Mac은 `Cmd+F`)로 고칠 문장 찾기
   - 섹션은 `<!-- ===== 섹션 이름 ===== -->` 표시로 나뉘어 있어요
3. 문장만 고치고 `<`, `>`로 된 태그는 건드리지 않기
4. 오른쪽 위 **Commit changes** → 1분쯤 뒤 사이트에 반영

## 사진 바꾸기
- `img` 폴더에 같은 이름으로 새 사진을 올리면 그대로 교체돼요.
